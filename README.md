# SkillNexis-Week1-Excel-Data-Fundamentals
Week 1 Internship Assignment - Excel Data Fundamentals and Sales Analysis
Week 1 – Excel & Data Fundamentals

Project

Global Superstore 2016 – Sales Performance Analysis

Files

- "Week1_Excel_Data_Analysis_Project.xlsx" – Cleaned dataset, practice answers, calculated summaries, Top 10 conditional formatting and dashboard charts.
- "Week1_Excel_Data_Fundamentals_Assignment.pdf" – Report with answers, formulas, calculated values, charts and project notes.

Practice Questions

1. Duplicate check and missing-value handling.
2. Region-wise sales summary (Rows: Region; Values: Sum of Sales).
3. Mean, median and mode using Excel formulas and calculated values.
4. Top 10 sales conditional formatting in the workbook.
5. Category-wise revenue bar chart.

Main Project

- Total Revenue
- Sales by Category
- Yearly Sales Trends
- Department-wise revenue limitation documented (no Department field in the supplied dataset).

**Important Note**

The summary sheets contain calculated aggregate tables, not native interactive Excel PivotTables. If native PivotTables are required, they must be created in Excel using the field layouts provided in the workbook and PDF.

Tools Used

- Microsoft Excel
- Global Superstore 2016 Dataset
